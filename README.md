# Smart Resume Builder

A full-stack web application for creating professional and ATS-friendly resumes.

## Features
- Personal, education, experience and skills sections
- Project, certification and achievement management
- Multiple resume templates
- Live resume preview
- ATS keyword analysis
- Save and manage resumes
- Export resume as PDF/TXT

## Technologies
- Java 17
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- HTML, CSS, JavaScript, Bootstrap
- Maven
- Git/GitHub

## Architecture
Frontend → REST API → Service Layer → Repository → MySQL
